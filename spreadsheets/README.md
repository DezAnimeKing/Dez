# Budget & Lifestyle Planner (Excel)

Two dark-theme Excel workbooks (Excel 365 / 2021+):

| File | Tabs |
|---|---|
| `Ultimate_Budget_Planner.xlsx` | Instructions, Setup, Payments, Manual Log, Accounts, Dashboard (weekly / bi-weekly / 4-weekly / monthly / quarterly / 6-month / annual / custom), Jan–Dec, Annual, Calendar, Savings, Debt Payoff, Debt Schedule |
| `Task_Habit_Tracker.xlsx` | Instructions, Setup, Dashboard, Recurring Schedule, Variable Tasks, Recurring Log, Tasks Filter, Daily, Weekly, Monthly, Decision Matrix, Habit Tracker, Gratitude Log, Goals |

Yellow cells are inputs; everything else is formula-driven. Sample data is included — overwrite it.

Regenerate with `python3 build_budget.py` / `python3 build_tasks.py` (needs `openpyxl`).
