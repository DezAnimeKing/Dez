# Money

> [!terminal] Log money in any daily note under **## Money**
> `- [spend:: 18.40] [cat:: Eating Out] [acct:: Credit Card 1] ramen after work`
> types: spend · income · bill · save · transfer · debt · sub  —  cat must match an Excel sub-category to land in the right table
> the sync script copies these lines into Excel ▸ Manual Log and pulls the budget back into [[Budget Snapshot]].

> [!grid]
> > [!card|teal] This month · from Excel
> > ```dataviewjs
> > const s = dv.page("03 Money/Budget Snapshot");
> > if (!s || !s.month) dv.paragraph("Run the Excel sync to fill this in.");
> > else {
> >   const m = n => "$" + Number(n || 0).toLocaleString(undefined, {maximumFractionDigits: 0});

> >     `<div class="xo-row"><span>${k}</span><span class="v">${m(a)} / ${m(b)}</span></div><progress class="${k !== "Income" && k !== "Savings" && a > b ? "over" : "teal"}" value="${b ? Math.min(1, a / b) : 0}" max="1"></progress>`).join(""));

>
> > [!card|pink] Spend by category · vault, this month
> > ```dataviewjs
> > const ym = dv.date("today").toFormat("yyyy-MM"), by = {};
> > for (const p of dv.pages('"01 Daily"').where(p => p.file.day && p.file.day.toFormat("yyyy-MM") === ym))
> >   for (const li of p.file.lists) if (li.spend) by[li.cat ?? "Other"] = (by[li.cat ?? "Other"] || 0) + Number(li.spend);
> > const tot = Object.values(by).reduce((a, b) => a + b, 0);
> > dv.el("div", Object.entries(by).sort((a, b) => b[1] - a[1]).map(([k, v]) =>
> >   `<div class="xo-row"><span>${k}</span><span class="v">$${v.toFixed(0)}</span></div><progress value="${v}" max="${tot}"></progress>`).join("") || "Nothing logged yet.");
> > ```

## Transactions logged in the vault
```dataviewjs
const rows = [];
for (const p of dv.pages('"01 Daily"').where(p => p.file.day).sort(p => p.file.day, "desc"))
  for (const li of p.file.lists) {
    const type = ["spend", "income", "bill", "save", "transfer", "debt", "sub"].find(k => li[k] !== undefined);
    if (!type) continue;
    rows.push([p.file.link, type, li.cat ?? "", "$" + Number(li[type]).toFixed(2), li.acct ?? "", li.to ?? ""]);
  }
dv.table(["Day", "Type", "Category", "Amount", "Account", "To"], rows.slice(0, 60));
```
